# Prototype

`trip-wardrobe.html` is the first version: a single page published as a Claude artifact. It plans outfits per day
from a wardrobe (added from photos, product links or by hand), estimates typical weather, and builds a packing list
with what's missing, what repeats and what to leave home.

It runs only inside claude.ai, where it uses the artifact runtime for storage, photo uploads and Claude calls. It is
kept here as the reference for the wardrobe, outfit and packing features (WRD, OUT, PCK in the feature map): the
prompts, the data shapes and the design tokens move into the real app in Phase 1.
